# Patient Registration App

A frontend-only web app to register and query patient data using `pg_lite`.

## Features

- Register new patients
- Run custom SQL queries
- Persistent storage across refreshes (IndexedDB)
- Multi-tab sync
- Fully frontend (no backend)

## Setup

Clone the repo and open `index.html` in any browser using Live Server extension.

Or visit the live deployment link if available.

## Tech Stack

- HTML, CSS, JavaScript
- [pg_lite](https://github.com/electric-sql/pglite)

# patient-registration-app# Patient Registration App (Frontend Only with PgLite)

A fully client-side patient registration app using [PgLite](https://electric-sql.com/docs/pglite) to persist data in the browser.

## 🚀 Features

- Register new patients (with validation)
- Run SQL queries on patient data
- Data persists across page refreshes
- Works across multiple tabs (IndexedDB)
- Fully responsive UI

## 🧠 Technologies

- HTML, CSS, JavaScript
- [PgLite](https://www.npmjs.com/package/@electric-sql/pglite)
